# Security

UCD Check is a folder of Markdown. The skill contains no scripts, no dependencies, no network calls and no telemetry. Installing it copies those files into a skills directory. It does not run code.

## Report a problem

If the skill text could mislead an agent into doing something harmful, or if a published copy has been tampered with, report it through this repository's private security advisories on GitHub.

Do not open a public issue for something that should stay private.

There is no application server to patch. A fix is a change to the Markdown, reviewed in the open after the private report is received.
