# Contributing

UCD Check reports rules that come from the bundled standards. A change to a rule needs the official source.

## Report a wrong or outdated rule

Open an issue on this repository. Include:

1. The file and heading in `skills/ucd/standards/` that is wrong.
2. The official page that disagrees with it. A GOV.UK, MoJ or W3C URL is required. A paraphrase is not enough.
3. The version you checked, if the rule depends on a version of GOV.UK Frontend or MoJ Frontend.

Do not add a rule the bundled pack does not contain, and do not write guidance from memory. If the official page has moved on, the official page wins until the bundled file is updated from a new UCD Context pack.

## What else helps

- A fixture under `evals/fixtures/` that shows the wrong result, and the finding you expected.
- A broken relative link, with the file that contains it.

## What this repository will not take

- A request for money, or a link that asks for it.
- A claim that the skill makes a service compliant, accessible or able to pass a service assessment.
- Client names, or contact details other than this repository.
